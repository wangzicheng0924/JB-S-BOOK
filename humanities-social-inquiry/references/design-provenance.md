# 设计来源与取舍

本技能于 2026-10-08 根据用户指定的七阶段流程编写。入口、阶段交接、学科指引与状态约定为本次独立撰写，未复制、翻译或打包外部技能正文。下面列出影响设计选择的参考项目，不代表已经安装、逐项实测或获得其作者认可。

| 参考来源 | 借鉴的设计方向 | 本技能的处理 |
|---|---|---|
| [skills-for-humanity](https://github.com/human-avatar/skills-for-humanity) | 按问题组织思考、表达与决策工具 | 围绕七步共享产物推进，取消逐步骤确认和强制多方法堆叠 |
| [Humanities Writing Companion](https://github.com/tizzy916/humanities-writing-companion) | 学科差异与论证先于语言修饰 | 区分直接协作与可选训练，遵守用户已有立场和修订范围 |
| [AI Anthropology Toolkit](https://github.com/MattArtzAnthro/AI-Anthropology-Toolkit) | 具体经验到更广判断之间的依据与边界 | 保留当事人意义、负面案例和概括条件，原作者理论与方法引用需要另行核验 |
| [ljg-skills](https://github.com/lijigang/ljg-skills) | 把概念、具体材料和可理解表达连接起来 | 不继承固定署名、Org 环境或预设一切问题都有单一本质 |
| [tronghieu agent-skills](https://github.com/tronghieu/agent-skills) | 将论证检查对应原文与反对意见 | 用户选择训练才先作答再比较；可直接讲解并给出实际产物 |
| [Thinking Toolkit](https://github.com/ponomr/thinking-toolkit) | 根据问题选择少量方法并交付结果 | 方法必须有独立增量；不把形式完整当作问题解决 |
| [Think](https://github.com/fheinonen/think) | 决策的前提、选项与复盘，以及从真实作品提炼方法 | 不把结果好坏等同于判断质量，经验规则绑定实际反馈与条件 |
| [dbskill](https://github.com/dontbesilent2025/dbskill) | 问题澄清与长期决策记录 | 保留最初判断与后续事实的区分，不采用对行动困难的预设心理归因 |

调研基于 2026-10-03 的公开项目检索与入口抽查，没有重新声称这些仓库在本技能编写日的安装量、Stars 或功能状态。后续直接复用外部代码或正文时应另查实际许可与当前版本。本技能运行不依赖上述项目在线可用。

当前可衔接的本地研究技能采用运行时发现；若缺失则用本技能内部流程继续。学科指引是问题处理的操作约定，不声称代替完整课程、原典研读或经验研究。
