# 人文社科问题研析

用于 Codex 的综合问题分析技能，带领用户从现实困惑或人文社科疑问逐步走向理解、表达与行动。

## 技能入口

[humanities-social-inquiry/SKILL.md](SKILL.md)

版本：1.0.0。

## 七阶段流程

把困惑变成问题 → 阅读和理解 → 学科分析 → 判断与论证 → 写作与交流 → 决策与行动 → 从经验中学习。

按问题选择哲学、社会学、人类学、历史学和文学方法。各阶段共享问题、材料和判断；收到新反馈后修订受影响的部分，保留原来的判断与修改依据。尚未执行的行动和未取得的反馈会明确标记。

## 安装与使用

下载本仓库，将整个 `humanities-social-inquiry` 文件夹放入 Codex 的技能目录（默认 `~/.codex/skills/`，设置了 `CODEX_HOME` 时使用该目录下的 `skills/`）。

示例：

```text
使用 $humanities-social-inquiry。我的困惑是：……请带我走完整个分析流程。
```

也可以指定仅处理某一阶段，或携带之前的分析记录继续。技能自身无需运行脚本；需要文献检索、田野或论文能力时，按环境实际可用的工具和技能衔接。

## 设计与验证

技能正文与支持文件为独立编写，设计参考和取舍见 [来源说明](references/design-provenance.md)。

已通过技能结构检查，以及社团组织、文学阅读两个合成案例和一轮后续反馈的行为验证。合成验证不代表真实调查或现实行动效果，也不代表所有学科路径均已独立实测。
