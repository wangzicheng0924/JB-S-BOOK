# 田野材料整理与分析

尚未收集材料而需要制定方案，或分析发现需定向补访时，读 [10-fieldwork-design.md](10-fieldwork-design.md)。调查计划、实施状态与实际取得的材料分别记录。

## 保持材料层次

先明确材料是逐字转录、节录、现场笔记、回忆还是他人整理。纠正识别错误时保存原版本和修订位置，不为使表达完整而补写原话。只读片段时不能报告整份访谈已分析。

保留人物代号、相关关系、场景、提问和前后话语；未知项不推测。研究者当时观察和后来的解释分开。受访者解释是研究对象的一部分，不自动是事件原因的独立证明。

分析前熟悉本次可读材料整体，记录意外、矛盾及可能与问题相关的片段。大材料库可分批处理，更新已读覆盖，先作可修订的小批分析；不得以摘要检索结果声称已读全库。

## 依据已选方法开展分析

### 民族志取向

围绕场景、行动、互动关系和实践过程组织片段。比较“人们如何说”“如何做”“在什么条件下变化”。保留现场次序和研究者在场可能产生的影响。厚描需要已有细节和意义语境，不授权文学化补场景。

### 主题分析

明确是反思性主题分析、编码簿取向还是编码一致性取向，不把它们混写为一种流程。

反思性主题分析可在熟悉资料、编码、发展和检视主题、明确主题意义及写作之间往返。主题要有共享意义的组织概念，不能仅是采访问题的标题。编码及主题记录是可变的分析笔记，不预设固定编码簿、独立编码一致性或“标准正确答案”；也不将饱和设为该路径通用的完成证明。合作分析可以讨论不同理解，无须以 Kappa 消除差异。

编码簿或一致性取向按其设计建立定义、纳入/排除条件和例子；需要计算一致性时先确认单位、多人独立编码和真实输入。一个模型反复编码不等于多个独立研究者。

上述区别依据 Braun 与 Clarke 的 [Understanding TA](https://www.thematicanalysis.net/understanding-ta/)、[FAQ](https://www.thematicanalysis.net/faqs/) 与 [审稿指南](https://www.thematicanalysis.net/editor-checklist/)（2026-10-02 核查）。这些要求针对相应 TA 路径，不扩展成所有质性研究禁令。

### 扎根理论

明确所采用传统和实际进行过的步骤。围绕行动/过程作初始分析，持续比较片段、案例、范畴及反例，记录范畴如何发展。Strauss–Corbin 的开放/主轴/选择性程序不作为所有流派的共同模板。

理论取样是依据发展中的分析补充材料，不能把已有便利样本改名为理论取样。没有实际迭代收集或充分范畴比较时，可报告借鉴持续比较的探索分析；不能补写已经实施的完整研究或宣告理论饱和。

### 框架分析与跨案例比较

按研究问题与资料发展分析维度，建立案例 × 维度矩阵；每个摘要保留原文位置。先理解个案再跨案例，不把脱离情境的引语拼成群体差异。矩阵中的空白可能表示未问、未记或未发生，只有回查后才能解释。

方法参考：[Gale et al., Using the framework method](https://pmc.ncbi.nlm.nih.gov/articles/PMC3848812/)（2013；2026-10-02 核查）。其具体应用场景不能自动推广为所有研究的固定步骤。

### 叙事与话语分析

叙事分析保留讲述的顺序、转折、受众和身份建构，区分讲述时间与事件时间；不要把完整叙事拆成跨人的碎片主题。话语分析明确具体取向，分析表达如何完成行动或构造对象/位置，必要时连回互动、文本生产和制度背景。不能只凭几个词频归因意识形态或动机。

## 从分析到解释

每个重要模式记录代表片段、变化/反例、出现条件和分析备忘录；不预设固定引语数量。罕见但重要的片段可改变解释，频率不能单独代表意义或总体比例。

采用 [analysis-record.md](../assets/analysis-record.md) 中适用字段。不是所有路径都要码表；场景记录、叙事梗概、文本细读同样可成为解释基础。需要理论连接时读 [06-theory-contribution.md](06-theory-contribution.md)。
